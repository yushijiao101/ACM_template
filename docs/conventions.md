# 模板约定

## 语言与类型

- 使用 GNU++17。
- 不使用可变长数组等非标准 C++ 写法。
- 可能溢出的整数默认使用 `long long`；乘法在取模前仍可能溢出时，单独使用 `__int128` 或说明输入限制。
- 避免 `#define int long long`，让类型含义保持清晰。

## 下标与范围

- 图和树默认 1-indexed。
- 数组、字符串和通用容器可按算法习惯使用 0-indexed，但文件头必须明确。
- 固定数组要写出上限含义；动态容器要说明有效编号范围。
- 区间接口必须说明是闭区间 `[l, r]` 还是半开区间 `[l, r)`。

## 文件结构

每个模板开头填写：

```cpp
/*
Algorithm:
Purpose:
Complexity:
Indexing:
Requirements:
Tested on:
Common mistakes:
Status:
*/
```

模板默认不带题目输入输出逻辑。若示例 `main` 有助于理解，应放到 `tests/`，避免复制时误带题目格式。

## 图与多测

- 图算法注明有向或无向、权值条件，以及重边、自环和不连通图的行为。
- 模板若保存全局状态，必须提供初始化或清空方式。
- 多测时重点清空邻接表、访问标记、时间戳、答案数组、队列/栈和动态节点计数器。

## 状态升级

`Unverified` → `Experimental` → `Stable` 不是强制的线性流程，但 `Stable` 必须同时满足：GNU++17 编译、至少一道明确验证题、适用范围完整、至少一名队友复核。仅本地测试不能替代验证题。
