# 常见错误清单

## 通用

- 数组上限只开到 `n`，却使用了 1-indexed 的 `n` 号位置。
- 多测只清空答案，没有清空计数器、邻接表或懒标记。
- `int` 加法或乘法溢出后才赋给 `long long`。
- 混用 `cin` 与 `getchar`，或在开启快速 I/O 后混用 C/C++ 输入。
- 空数组、空模式串、`n = 0`、`l > r` 等边界未定义。

## 图论

- Dijkstra 用于负权边，或距离类型过小。
- 只从 1 号点 DFS，漏掉不连通分量。
- 无向边只加一次，或边数组容量忘记按双向边计算。
- Tarjan 中无向图没有按边编号跳过反向边。
- 拓扑排序没有检查输出节点数，误把有环图当作成功。

## 数据结构

- Fenwick 在下标 0 更新导致死循环。
- 线段树区间端点混用 0-indexed 和 1-indexed。
- 懒标记没有在建树或多测前清空。
- 稀疏表查询长度的对数计算有浮点误差或表宽不足。

## 字符串

- KMP 匹配成功后没有回退，漏掉重叠匹配。
- Trie 字符映射超出字母表范围。
- AC 自动机的终止标记在一次查询中被破坏，导致后续查询错误。

## 数学

- 快速幂没有规范化负底数，或 `mod <= 0` 未定义。
- 筛法从 `i * i` 开始时使用 `int` 乘法溢出。
- 扩展欧几里得的负数除法、系数符号与模逆元范围处理不一致。
